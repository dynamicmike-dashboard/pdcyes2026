## Work Completed

### 1. Fixed Server-Side Exception (Digest `2508316783`)
**Root Cause:** `components/SpeakerCard.tsx` contained an `onError` image fallback event handler but was missing the `"use client"` directive. React Server Components cannot handle browser event handlers, causing SSR to crash on Vercel.

**Fix:**
- Added `"use client"` to `SpeakerCard.tsx`
- Refactored `app/events/[slug]/page.tsx` to use native Next.js `generateMetadata()` instead of the custom `<SEOHead>` JSX component (which caused issues in the App Router metadata context)

**Verified:** Local `npm run build` passed cleanly (14/14 static pages, 0 errors).

---

### 2. Fixed Stale Page Cache
**Root Cause:** `export const revalidate = 60` on the event detail page caused Vercel to serve a cached version for up to 60 seconds after edits, so image and content changes appeared not to save.

**Fix:** Changed to `export const dynamic = "force-dynamic"` so the page always fetches the latest data from GitHub on every request.

---

### 3. Fixed Stale SHA in Edit Form
**Root Cause:** The edit form was passing `sha: initialValues?.sha` (the SHA fetched when the page first loaded). If the file was already updated between page load and form submit, this stale SHA could cause write conflicts.

**Fix:** Removed the SHA from the edit form payload entirely. The `/api/github` `update` action already auto-fetches the current SHA from GitHub before writing, so this was safe to remove.

---

### 4. Enhanced MarkdownBody — URL Hyperlinking
**Root Cause:** Raw URLs in event body text (e.g. WhatsApp links) were rendering as plain text.

**Fix:** Rewrote `components/MarkdownBody.tsx` with a tokenization-based renderer that:
- Converts `[text](url)` markdown links to `<a>` tags
- Auto-hyperlinks raw `https://` and `http://` URLs
- Renders `**bold**` and `*italic*` markdown
- Opens all links in a new tab with `rel="noopener noreferrer"`

---

### 5. Improved Registration Link CTA
**Issue:** The Registration Link field in the admin form was not visually prominent on the public event page; also used `bg-accent` which wasn't rendering correctly.

**Fix:** Replaced the basic button with a styled amber card section containing:
- A bold primary-coloured "Register Now →" button
- The raw URL shown as a secondary hyperlink below
- Only renders when `registration_link` is non-empty

## Data Permanence — Confirmed

All event edits are permanently stored as markdown files in `/content/events/` in the GitHub repository with full git history. Every save from the admin creates a new commit. Events are recoverable at any version indefinitely.
